劉璇之｜能力概況與轉職策略盤點（2026/07/23 更新版）

具備 10 年網頁視覺設計與 RWD 切版資歷，目前正透過 AI 輔助與專案實作，轉型為能獨立處理資料流與狀態管理的 Vue 前端工程師。  
一、 求職策略與個人定位
1. 履歷與對外定位

    求職定位：「具備 10 年網頁視覺與 RWD 切版經驗的 Vue 前端工程師」

      

    優勢切入點：兼具「高質感網頁視覺、95% 精準切版還原度、RWD 細節」與「Vue3 + API 資料流開發能力」。能大幅降低團隊在 UI 調整與前後端溝通上的成本。  

2. 求職目標

    目標職缺：Vue 前端工程師（Vue Frontend Engineer）  

    核心期望：擺脫「純切版 / 純網頁設計」的框架，專注於 Vue3 開發、API 串接、Pinia 狀態管理、Component 模組化。  

    工作內容接受度：可以接受 30%~50% 以下的 UI 視覺/切版維護，但核心必須是前端邏輯與資料流處理。  

3. 目標產業與市場方向（優先選擇自有產品公司 In-house）

    D2C 品牌電商 / 跨境電商 / MarTech 平台：極度看重視覺質感、購物車狀態管理與 API 串接。  

    影音媒體 / 數位內容 / 線上教育平台：強調前台 RWD 排版美感、媒體播放互動與 Vue 元件維護。  

    ESG 永續科技 / HRTech / B2B SaaS 企業前台門戶：需將複雜數據轉化為清晰 UI，極度看重元件重用性與表單處理。  

    高階客製化 Web App / 數位科技顧問公司：專案密集度高，能快速累積前後端分離的實戰經驗。  

二、 個人特質與學習模式
思考模式

    做事偏謹慎，追求精準度。  

    喜歡理解原理與系統流程，而不是死背語法。  

    對陌生領域會先確認名詞定義，不喜歡憑印象回答。  

    約有 80% 把握才願意輸出想法（需注意避免因過度謹慎而自我低估）。  

學習模式

    專案導向學習（Project-based Learning）：無實際應用情境易失去動力，在實作中補強技術最為高效。  

    善於跨領域整合資訊，並能靈活運用 AI 工具（ChatGPT / Claude）輔助學習、解構原理與 Debug。

    核心優勢：網頁視覺設計、 RWD 設計、網頁 Layout 排版、視覺細節與切版還原度。  

    經驗說明：擅長 Corporate Website、Landing Page、品牌官網、活動頁、影片內容平台。（註：無標準 SaaS/App 產品設計 Product Design 實務經驗，不以此為主打）  

2. HTML / CSS / SCSS

    HTML (★★★★☆)：熟悉 Form、Table、SVG、iframe、SEO 基本結構。  

    CSS (★★★★☆)：熟悉 Flexbox (★★★★☆)、Grid (★★☆☆☆)、Position (★★★★☆)、RWD (★★★★☆)、Animation / Transition (★★★★★)。  

    SCSS (★★☆☆☆)：熟悉 Nesting、Mixin，可配合專案擴充。  

3. JavaScript（目前優先補強重點）

    現階段能力 (★★☆☆☆)：基本語法、Array/Object 操作、DOM 基本操作、fetch API 串接、Template Literal。  

    衝刺目標：

        理解 JS 基本原理（Execution Context, Scope, Event Loop）  

4. Vue3 生態系（目前優先補強重點）

    現階段能力 (★★☆☆☆)：使用 Vite 建置專案、基礎 Component 拆分與修改。  

    衝刺目標：

        建立良好的 Component 拆分與設計模式  

5. API / Git / 開發工具

    API (★★☆☆☆)：熟 GET 串接，需補強 POST/PUT/DELETE、HTTP Status Code、Error Handling 與 Loading 狀態控管。  

    Git (★★★☆☆)：熟 clone, commit, push, pull，需補強 Branch 策略與 Conflict 解決。  

    開發工具：VS Code、Chrome DevTools (Debug)、npm、Vite。

為了弭平「缺乏大型 Vue 專案實作經驗」的弱點，目標集中打造 1 款高質感、具備完整資料流的 Vue3 中型 SPA 專案：  
專案主題建議

    主題方向：D2C 品牌電商購物平台 或 影音串流/數位內容平台 前台系統。
